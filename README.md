# pi-tva-toolbox

A Time Variance Authority (TVA) inspired toolbox for manipulating Pi coding agent sessions (the multiverse). 

Pi sessions are append-only Directed Acyclic Graphs (DAGs) of JSON objects. This extension provides utilities to prune dead branches, extract timelines (time heists), and safely manage session context without losing the "Sacred Timeline".

## Installation

This extension is designed to be loaded by the Pi coding agent.
